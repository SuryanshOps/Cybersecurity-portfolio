### 📑 1.2 Hacker Types & Ethics
* **Filename:** `1.2_hacker_types_and_ethics.md`
* **Core Focus:** Taxonomy of systemic threat actors, tracking tactical skills (Script Kiddies versus Advanced Persistent Threats), and analyzing legal and ethical codes of conduct.
* **Profiles Evaluated:**

  * **Advanced Persistent Threats (APTs):** State-sponsored or deep-tier organized groups executing prolonged, targeted infrastructure compromises.

### 📑 1.3 Malware Types & Behaviors
* **Filename:** `1.3_malware_types_and_behaviors.md`
* **Core Focus:** Distinguishing and categorizing malicious payloads using their functional replication vectors and localized behavior trees.
* **Malware Taxonomy:**
  * **Viruses:** Coded payloads dependent on host file integration and human trigger vectors to spread.
  * **Worms:** Standalone autonomous software programs that self-replicate continuously across network topologies.
  * **Trojans:** Malicious components disguised as benign tools to trick administrative deployment.
  * **Ransomware:** Cryptographic lockers that isolate filesystem sectors to demand economic extortion keys.

#### 🖼️ Malware Proliferation Comparison Matrix

| Malware Class | Autonomous Replication | Requires Host File | Principal Impact Mode |
| :--- | :---: | :---: | :--- |
| **Virus** | ❌ No |  Yes | File Corruption & Instability |
| **Worm** |  Yes | ❌ No | Host Bandwidth Exhaustion |
| **Trojan** | ❌ No | ❌ No | Backdoor Ingress Creation |
| **Ransomware** |  Yes | Variable | Cryptographic System Locking |
